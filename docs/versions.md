# Third-party software versions

Versions used for the analyses reported in the Data Descriptor (as stated in the manuscript). Custom scripts are Python 3; see `environment.yml` for the Python-package environment.

| Software | Version | Role |
|---|---|---|
| hifiasm | 0.19 | genome assembly |
| nextPolish2 | 0.2 | assembly polishing |
| Juicer | 1.6 | Hi-C read processing |
| 3D-DNA | 180922 | Hi-C scaffolding |
| YaHS | 1.2 | Hi-C scaffolding (alternative) |
| Merqury | 1.3 | assembly QV / k-mer completeness |
| BUSCO | 5.4 | completeness (genome + protein, apicomplexa_odb10) |
| minimap2 | 2.26 | read / genome alignment |
| samtools | 1.19 | BAM handling |
| STAR | 2.7.11 | RNA-seq alignment |
| featureCounts | 2.0 | read counting |
| StringTie | 2.2 | transcript assembly |
| gffcompare | 0.12 | GTF comparison |
| CPC2 | 0.1 | coding-potential prediction |
| PLEK | 1.2 | coding-potential prediction |
| hmmscan (HMMER) | 3.3 | Pfam domain scan |
| BLAST+ | 2.14 | homology search |
| MAFFT | 7.5 | multiple sequence alignment |
| Boltz-2 | 2.1 | protein structure prediction |
| Foldseek | 9 | structure similarity search |

Structure models are archived at [Zenodo](https://zenodo.org/records/24101801) (DOI 10.5281/zenodo.24101801).
